## Summary

Held workspaces no longer exit the process. All `SystemExit(1)` hold paths in `simple_coding_agent/lifecycle.py` now retain the checkpoint/branch/tree and return to the poll loop; only the consecutive-error limit still exits. Unreadable checkpoint/ledger at startup enters a new startup-hold state (held, quiet polls, status-visible, repair-resumable) instead of crash-looping.
