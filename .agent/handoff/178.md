## Summary

Implemented the issue #178 fix on branch `agent/issue-178` and committed it
as `0a3fe91` ("Gate finishing on code-review and surface the completion
decision"). The work addresses the silent-`incomplete` bug where an attempt
that commits changes but never invokes `code-review` ends as `incomplete`
with no visible reason:

1. **Review gate on finishing** (`simple_coding_agent/model_execution.py`):
   new `Stop` hook `_gate_review_on_stop` blocks the first finish attempt
   with "Invoke the `code-review` skill on your changes before finishing"
   when the branch holds commits added by this run and no `code-review` was
   observed. Once per run; runs with no new commits (or no commit provider)
   are never nudged. New `set_new_commits_provider` seam supplies the
   new-commit count.
2. **Decision surfaced** (`simple_coding_agent/lifecycle.py`): new
   `completion_decided` event (outcome + reasons) emitted after every
   `evaluate()` (main path and `_run_preparation` setup/baseline path);
   for `incomplete`/`no_changes` the issue-comment Details section now
   carries the evaluator's reasons instead of the generic SDK explanation.
3. **Comment clarified** (`simple_coding_agent/publication.py`,
   `lifecycle.py`): new `reviews_performed` field on `AttemptEvidence` and
   `PublicationRequest` (both defaulted to 0, so old constructions still
   work); result comment and PR body now render `Reviews performed: N` and
   `Review repair cycles: M/2` separately plus a `code-review was not run`
   line when N == 0.
4. **Prompts** (`lifecycle.py` `_gate_section` and the continuation pointer):
   both now state that an attempt with commits but no `code-review`
   invocation in the run is classified `incomplete`.

New tests (all passing when last run): 7 Stop-hook tests in
`tests/test_model_execution.py`, 6 runner tests in
`tests/test_model_attempt_runner.py` (prompt wording, incomplete reason +
event, reviewed-run eligibility, provider wiring, setup-failure event),
4 comment/PR-body tests in `tests/test_publication.py`.
