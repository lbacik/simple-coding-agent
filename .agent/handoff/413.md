## Summary

Implementing ADR 0011 (finish-or-preserve a paused rebase). Done so far, all uncommitted on `agent/issue-413`:

- `simple_coding_agent/git_workspace.py`: added `PausedRebasePreserved` / `PausedRebaseFinish` dataclasses; `RebaseConflictError` now carries optional `preserved_ref`/`preserved_revision`; new `preserve_paused_rebase()` (non-destructive snapshot via throwaway `GIT_INDEX_FILE`, emits `rebase_paused_work_preserved`), `_snapshot_workspace_for_abort()`, `finish_paused_rebase()` (preserve → gate on unmerged/markers → `stash push --keep-index -u` → manual pick commit via `git commit -C REBASE_HEAD` → pop/stash-drop → mid-rebase seal commit with `Attempt-Id` trailer → `git -c core.editor=true rebase --continue` loop, max 20; deletes Preserved ref on success), `clean_untracked()` (`git clean -fd`); `abort_unresolved_rebase()` now requires `issue_number`/`attempt_id`, preserves first, returns the kept revision; `cleanup()` accepts optional `issue_number`/`attempt_id` and preserves best-effort when a rebase is paused. Git behavior verified with scratch experiments: unstaged edits block `rebase --continue` (untracked do not), seal-before-continue folds the pick message, manual-commit-then-seal-then-continue yields pick → seal → remaining picks in order, and a mid-rebase note commit stays reachable.
- `simple_coding_agent/attempt_workspace.py`: Protocol extended with the new operations and signatures (also `cleanup` optional params).
- `tests/fakes.py`: `InMemoryWorkspace` implements the new seam (`abort` preserves, `finish` completes or returns configured `finish_unresolvable`, `clean_untracked`, `cleanup` preserves when paused).
- `tests/test_git_workspace.py`: updated the 3 `abort_unresolved_rebase` call sites for the new kwargs; full file passes (56 passed).
